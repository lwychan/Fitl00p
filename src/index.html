Diabetes tracking Nightscout — NOT medical software

Connects to your own Nightscout site (fed by tconnectsync, xDrip, Loop, or any Nightscout uploader) to pull glucose, bolus and basal history. A single-user, heuristic pattern-spotting tool built on population-average insulin curves — not a clinical dosing calculator. It never writes anything back to your pump or CGM.

The correction factor is used until there's enough of your own resolved corrections to learn one from scratch (it'll then prefer the learned value automatically) — set it to whatever your pump is currently programmed with, and change it any time it doesn't seem right.

Insulin curve is pre-set for Lyumjev (peak ~57min, ~4h duration). Change it below if you use a different rapid-acting insulin.

MyFitnessPal import

MyFitnessPal blocks server-side access to diaries, so this works as a bookmarklet instead: a button you drag to your bookmarks bar. Open your own MFP diary while logged in, tap it, and it reads the page directly in your session and sends today's food to fitl00p — no password ever touches this app. For best results, turn on the Carbs/Fat/Protein columns under MFP → Settings → Diary Settings → Nutrients Displayed.

This is meant to be the fast path to a dose: log a meal in MFP, tap the bookmarklet, and it shows you a suggested dose right there — the same current-glucose/IOB-aware calculation as the Meal bolus calculator below, using whatever you already logged instead of retyping it. If you'd already dosed before syncing, it matches to that bolus instead; if it's a hypo treatment (glucose low or falling), it skips the suggestion entirely. Once you've actually dosed for a suggested item, link the real bolus to it in the Diabetes tab so fitl00p can learn from what you actually did.

On a computer: drag this button to your bookmarks bar.
