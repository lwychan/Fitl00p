# Sleep Sessions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store every sleep session per day (night, nap, doze) so naps stop overwriting nights, credit naps against sleep debt and tonight's need, and show naps in Body Battery and on the dashboard.

**Architecture:** One pure UMD module, `src/sleep-sessions.js`, holds the classifier and the nap-credit maths. The web app, the Edge Function and the iOS build all use it (the iOS build sends raw sessions, so there is one classifier, not two). A new `sleep_sessions` table holds every session; `health_daily.sleep_*` keeps the night only, so widgets, briefings and readiness keep working. A one-tap doze prompt covers lie-ins that HealthKit missed.

**Tech Stack:** Vanilla JS PWA (`src/`, no build step), Capacitor 8 iOS (Swift `HealthBackgroundSync.swift`), Supabase Postgres with RLS, Deno Edge Functions (`health-ingest`), `node:test` via `npm test`.

**Spec:** `docs/superpowers/specs/2026-11-12-sleep-sessions-design.md` (approved 2026-11-12). This plan deviates from it in one place, noted under Global Constraints.

## Global Constraints

- Session grouping: segments less than **90 min** apart form one session (unchanged from today).
- Night: the longest session that ends before **12:00 local** on the wake date and starts after **18:00 the day before**.
- Doze: a session starting within **2 h** after the night ends, same wake date.
- Nap: any other session with at least **0.25 h (15 min)** asleep.
- Nap credit toward **sleep debt**: **75%** of asleep hours, 7-night window, no cap beyond the existing debt cap.
- Nap credit toward **tonight's need**: **25%** of asleep hours, capped at **0.5 h**, only if the nap ends by **16:30 local**.
- Dozes count as part of the night they follow (added to the night's asleep total), not as naps.
- Body Battery sessions use **quality = 1** for naps and dozes.
- Backfill window: **30 days**.
- Lie-in prompt: one tap, prefilled with alarm time and suggested end; ignoring it changes nothing.
- **Deviation from spec (my call):** classification runs in the `health-ingest` Edge Function, from raw sessions the iOS build sends, not in Swift. The spec said "on the device". Reason: one classifier, shared with the web fallback, instead of a Swift copy that can drift.
- `health_daily.sleep_*` is always the **night** session for that wake date. Naps and dozes never go there.
- New `src/*.js` modules go in `sw.js` `NEVER_CACHE`. `src/` shared copies are generated only by `node scripts/sync-shared.mjs`; never hand-edit `supabase/functions/_shared/`.
- Pushing `main` or triggering a TestFlight build needs the owner's explicit yes (CLAUDE.md).

## Review Focus

1. A sleep that spans midnight (e.g. 23:59 → 07:00) must be one night, not split. Test in Task 1.
2. A late sleeper who wakes after 12:00 has no session ending before noon: the longest session on that wake date must still be the night. Test in Task 1.
3. A session with only `inBed`/`awake` samples must produce no row. Test in Task 1 (via the iOS-side raw input contract in Task 4).
4. Re-syncing the same HealthKit data must not duplicate sessions. Test in Task 4 (upsert key).
5. A session over 14 h (Gemma 2026-11-08 shows 11.99 h from 13:16) must be stored, but flagged for review rather than silently treated as a normal night. Test in Task 1.

## Interfaces (shared by all tasks)

```
// src/sleep-sessions.js (UMD, exports object SleepSessions)
type RawSession = { start: number /*ms*/, end: number /*ms*/, asleepHrs: number,
                    deepHrs?: number, remHrs?: number, coreHrs?: number }
type Session    = RawSession & { kind: 'night' | 'nap' | 'doze', wakeDate: string /*YYYY-MM-DD local*/,
                                 flag?: 'long' }
classifySessions(raw: RawSession[], localDate: (ms:number)=>string, localHour: (ms:number)=>number)
  -> Session[]                       // every session kept, none dropped by a later one
napDebtCreditHrs(naps: Session[]) -> number          // 0.75 * sum(asleepHrs of naps)
napTonightCreditHrs(naps: Session[], todayDate: string) -> number   // see constraints
dozePromptNeeded(nowMs, alarmHour: number /*e.g. 5.5*/, sessions: Session[], localDate, localHour) -> {needed: boolean, suggestedStart: number, suggestedEnd: number}
```

`supabase/functions/_shared/sleep-sessions.ts` is the Deno copy generated by `scripts/sync-shared.mjs` (Task 2).
